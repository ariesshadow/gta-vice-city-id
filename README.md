# Vice City Customs // ID & Permit Generator 🎮

An interactive, GTA VI-inspired web application designed for the **Build with React Image Editor Challenge** by Unlayer. 

**Vice City Customs** allows users to create, customize, and export their own official Vice City Police Department (VCPD) criminal record ID badges and permits.

---

## 🌴 Features

* **Custom Portrait Canvas:** Upload your own photo and auto-fit it cleanly into the VCPD badge photo frame.
* **GTA VI Neon Aesthetic:** Retro Vice City color scheme featuring glowing neon borders, high-contrast typography, and VCPD clearance details.
* **Real-Time Image Adjustments:** Adjust image brightness and neon saturation on the fly using live canvas filters.
* **Custom Badge Metadata:** Edit subject alias, primary criminal offense, and active bounty amounts.
* **Dynamic Overlay Stamps:** Add angled, high-impact overlay text stamps (such as `WANTED`, `BUSTED`, or `VICE CITY P.D.`).
* **High-Res Export:** Export the finished badge layout into a high-resolution PNG ready for sharing.

## 🌴🌴 New Features

* Real-time 3D WebGL Card Model (built with Three.js)
* Dual Export Pipeline (High-Res 2D PNG Badge + 4-Second 3D WebM Video Clip)
* Auto-Resizing Stamp Overlays & 5-Star Wanted Level Logic
* Multi-Template Styling & Holographic VCPD Seal
---

## 🛠️ Built With

* **HTML5 Canvas API:** For real-time graphics rendering, photo clipping, and visual filter effects.
* **CSS3:** Retro neon styling and grid-based responsive layout.
* **JavaScript (ES6):** Live state manipulation, file handling, and image export pipelines.
